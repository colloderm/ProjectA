## 0. 한 줄 요약
잘 키운 용병을 은퇴시키고 더 능력 있는 용병을 사서 다시 키우는 **용병 가문 육성**(웹 버전 Mercenary Legacy의 메타)과,
그 용병을 직접 조종해 몰려오는 적 속에서 버티다 **언제 탈출할지 판단하는 서바이버라이크 원정**을 결합한 쿼터뷰 3D 로그라이트.
원정은 **방을 골라 내려가는 던전**이고, 구역 끝의 **탈출 문**에서 나갈지 정한다. **욕심낼수록 쫓기고(탐욕의 냄새), 죽은 용병은 던전에 남는다(전사자의 묘비).**

## 1. 의도 (왜 만드는가)
- **핵심 재미 [확정]**: "잘 키운 용병 → 은퇴 → 더 능력 있는 용병 구입 → 다시 육성"의 갈아타기 순환.
- 웹 버전은 전투가 자동이라 "손으로 하는 재미"가 비어 있었다 → 원정을 직접 조작하는 액션으로 채운다.
- 긴장의 근원: **영구 사망은 전부 잃는다 [확정]**. 그래서 매 원정의 "탈출할까/버틸까"와, 용병 단위의 "언제 은퇴시킬까"라는 두 겹의 판단이 생긴다.

  가문 → 가문 강화, 유산 재능 확인
  의뢰판 → 이번 원정 의뢰 1개 선택
  출정 ─────────────────────────┐
                                ▼

   │  방이 끝날 때마다 포털 3개 중 다음 방 선택 (일반/정예/황금/휴식터/상점/묘비)

   └ 사망                     → 용병·장착 장비·원정 획득물 전부 소실, 명예의 전당 "전사"
                                ▼
[길드 허브] 계약 후보 갱신 → 계속 원정 / 은퇴 / 판매

## 6. 원정 (액션 층)

### 6.1 조작·카메라 [확정 + 제안]
- [확정] 자동 공격 + 이동 + 대시.
- [제안] WASD 이동, Space 대시(짧은 무적 0.25s, 거리 약 400uu), ESC 일시정지. 패드 지원(좌스틱 이동, A/남쪽 버튼 대시).
- [제안] 쿼터뷰 고정 카메라(회전·줌 없음, 피치 약 55°).
- [제안] 기본 공격은 가장 가까운 적을 자동 조준.
- [제안] 이동 속도는 모든 용병 고정(밸런스 기준점).

### 6.2 한 판 구조 — 방 선택형 던전 [확정 2026-11-12, v0.2의 시간형 단계 + 탈출 포털을 대체]
- 이 문서의 "단계"는 이제 **"구역"**과 같은 뜻(드롭 표·보상 배율·용병 경험치의 단계 = 구역).

| 구역 | 방 수 | 적 | 보상 배율 | 구역 끝 |
|---|---|---|---|---|
| 1구역 | 3 | 기본 적 2종 | ×1.0 | 탈출 문 |
| 2구역 | 3 | +2종, 엘리트 | ×1.6 | 탈출 문 |
| 3구역 | 2 + 보스방 | +2종, 엘리트 증가 | ×2.5 | 보스방 앞 탈출 문(마지막 기회) |

- **방** [확정]: 아레나 맵 1개를 재사용하고, 방마다 조명·적 구성·목표만 바뀐다 [제안]. 한 판 약 15~18분 목표 [제안].
- **처치 수 웨이브** [확정 2026-11-12, 시간제 대체]: 방마다 구역별 **처치 수**(출발점 1구역 80 / 2구역 150 / 3구역 220)만큼만 적이 나온다. 다 나온 뒤 필드 위 적이 0이 되면 방 종료. 시간 제한 없음 → 방에서 얻을 수 있는 경험치를 놓치지 않는다(성장의 재미 우선). 방 길이는 처치 속도에 따라 달라진다.
- **방 끝** [확정]: 적이 0이 되면 자동 기술이 멈추고, 필드 위 획득물(경험치·골드·아이템)이 히어로에게 **빠르게 날아와 흡수**된다. **마지막 획득물이 닿은 뒤** 히어로가 **서 있는 자리 기준**으로 **포털 3개**(화면 위쪽)와, 구역 끝이면 **탈출 문**(포털 줄 오른쪽)이 열린다. 배치는 아레나 경계 안으로 통째로 당겨 넣는다. 포털 무리에서 일정 거리(출발점 1000) 이상 멀어지면 히어로 주위에 포털 방향 화살표가 뜬다(탈출 문은 포털 옆이라 화살표 없음). 포털 위에 다음 방 종류 아이콘이 보이고, 플레이어가 걸어 들어가 고른다. 포털은 **다음 방으로 가는 길**일 뿐 탈출이 아니다.
- **탈출 문** [확정]: 포털과 별개의 문. **구역 끝(구역의 마지막 방을 마친 뒤)에만** 등장. 문에 1.5초 서 있으면 탈출 [제안].
- 포털 3개 규칙 [제안]: 3개는 서로 다른 종류, 각 구역 첫 방은 전투 방, 휴식터·상점은 연속으로 안 나옴, 묘비 방은 조건 충족 시에만(§6.2.3). 등장 가중치 출발점: 일반 45 / 정예 20 / 황금 10 / 휴식터 12 / 상점 13.
- [확정] 보스 처치 = 강제 탈출 + 큰 보상. 보스전 패배 = 사망.
- [확정] 골드·아이템·용병 경험치는 **탈출 성공 시에만** 지급.
- [제안] 보상 배율은 그 구역에서 얻은 획득물에 적용(1구역에서 주운 것은 ×1.0 유지). 화면 우상단에 "지금 탈출 시 획득: 골드 / 아이템 수 / 용병 경험치"를 상시 표시.
- 방 사이 전환 [제안]: 화면 페이드 → 남은 적·보석 정리(보석은 자동 흡수) → 히어로를 아레나 중앙으로 → 다음 방 설정 적용. 판 레벨·기술·HP는 그대로 유지.

### 6.2.2 탐욕의 냄새 [확정 2026-11-12 / 제안 수치]
- 미확보 획득물(원정 골드 + 아이템 1개당 골드 환산값)이 쌓일수록 **냄새 단계 0~4**가 오른다. HUD에 게이지 표시.
- 단계당 효과 [제안]: 스폰량(방 처치 수) +15%, 적 이동 속도 +5%. 3단계 이상이면 전투 방(일반·황금·정예)마다 **추격자 1마리** 추가: 신속 엘리트, 방 시작 10초 뒤 화면 위쪽에서 등장, 잡아야 방이 끝남(황금 방은 위협만) [확정 2026-11-16].
- 적용 시점 [확정 2026-11-12]: 방 도중이 아니라 **다음 방 시작 시** 그때의 단계로 적용. HUD는 "골드 N · 탐욕 L/4" 텍스트(게이지 아트는 M10).
- 상점에서 골드를 쓰면 미확보 골드가 줄어 냄새도 내려가고, 판매로 골드를 받으면 올라간다. 탈출하면 0.
- 단계 기준값 [제안]: 골드 환산 100 / 250 / 500 / 900 × 용병 등급 골드 보정(§8.6) — 높은 등급도 같은 체감이 되도록.
- 의도: 어려움이 시간이 아니라 **욕심**에 비례. "나갈까"의 기준이 내 가방이 된다. 위험: 깊이 보상이 냄새를 이기지 못하면 실패 조건(§2)에 걸리므로 회색 박스에서 우선 조정.

### 6.2.3 전사자의 묘비 [확정 2026-11-12 / 제안 세부, 저장 이후 M9]

- 원칙과의 관계 [확정]: 사망은 여전히 **전부 소실, 계승 없음**. 묘비 회수는 자동 반환이 아니라 목숨을 걸고 얻는 **새 보상**이다.

- 수치 [확정 2026-11-17 / BP에서 조정]: HP 4000, 이동 220, 접촉 10, 몸 반지름 150, 패턴 간격 3초(같은 패턴 연속 없음). 돌진: 예고 1.0초(길이 1440·폭 200) → 1600 속도로 0.9초. 포효: 예고 1.5초 → 보스로부터 300~1200 거리면 피해 25. 소환: 박쥐 8마리(HP 50% 이하부터 순서에 추가). 격노: 180초부터 30초마다 이동 +10%·패턴 간격 −10%(최대 5단계).
- 보스 방: 일반 적·추격자·탐욕 효과 없음. 처치 → 박쥐 정리, 2초 "보스 처치!" → 보상 골드 750 즉시 지급 → 강제 탈출. 보스는 적 시스템 안의 한 마리라 모든 기술이 그대로 맞음(큰 적은 몸 반지름으로 판정).

### 6.6 사망·중도 종료
- [확정] 사망 = 용병 영구 소실 + 장착 장비 소실 + 원정 획득물 전부 소실. 계승 없음.
- [제안] 기본 단검(길드 지급)은 소실되지 않음.
- [제안] 원정 중 메뉴에서 나가기 = "원정 포기" 확인창 → 사망 처리.
- **강제 종료·크래시 처리 [확정: (c) 원정 전으로 되돌림]**: 원정 시작 시 저장 데이터에 "원정 중" 플래그를 기록. 재실행 시 플래그가 남아 있으면 → 용병·장착 장비는 원정 출발 직전 상태로 유지, 원정 획득물(골드·아이템·경험치)만 소실, 플래그 해제 후 "원정이 비정상 종료되어 획득물이 사라졌습니다" 안내.
  - 이유: EA 초기 크래시로 용병이 죽으면 리뷰 직격탄. 강제 종료 꼼수는 획득물 전부를 대가로 치르고, 싱글 게임이라 피해는 본인 몫.
  - 정식 출시 때 안정성이 확보되면 (a) 사망 처리로 바꿀지 재검토.
  - 메뉴의 "원정 포기"는 여전히 사망 처리(의도적 선택이므로).

## 7. 용병 (육성 층)

### 7.1 등급 [확정: 웹 수치 출발점]
| 등급 | F | E | D | C | B | A | S |
|---|---|---|---|---|---|---|---|
| 성장계수 | 1.00 | 1.12 | 1.26 | 1.42 | 1.62 | 1.85 | 2.15 |
| 재능 슬롯 | 1 | 1 | 2 | 2 | 3 | 3 | 4 |
| 최대 레벨 | 20 | 30 | 40 | 55 | 70 | 90 | 120 |
| 계약 골드 | 0 | 250 | 750 | 2,200 | 6,500 | 18,000 | 50,000 |
| 은퇴 기본 포인트 | 1 | 2 | 4 | 8 | 16 | 32 | 64 |
- 기본 능력치 범위는 웹 `db.js` GRADES.base를 그대로 가져온다 [빌더].
- 등급별 최대 레벨은 웹 값을 유지한다.

### 7.1.1 용병 수명과 경험치 [확정: 목표 / 제안: 공식]
- **목표 수명 (탈출 성공 원정 기준, 최대 레벨까지)**: F 3~5회 · D 6~8회 · S 15~20회. E/C/B/A는 그 사이를 보간(E 4~6, C 8~11, B 10~14, A 13~17) [제안].
- **용병 경험치 출처** (탈출 시에만 지급): `(처치 수 × 1 + 엘리트 처치 × 10 + 도달 구역 보너스[1구역 50 / 2구역 150 / 3구역 350 / 보스 처치 800] + 의뢰 보상) × 구역 보상 배율` [제안 출발점].
- **경험치 곡선**: 웹 `floor(50 × L^1.55)`는 S(최대 Lv120)에서 수명 목표를 크게 넘으므로 그대로 쓰지 않는다. 등급별로 "목표 원정 횟수 × 평균 원정 경험치 = 최대 레벨까지 총 경험치"가 되도록 등급별 배수 테이블로 맞춘다 [제안]. 곡선 모양(초반 빠르고 후반 느림)은 웹 지수 1.55를 유지.
  - [M7-1 구현 2026-11-17] 필요 경험치 = `floor(50 × L^1.55 × Scale)`, `Scale = TargetRuns × ExpectedRunXP / Σ(L=1..최대−1) 50 × L^1.55`. TargetRuns(목표 중간값) F 4 / E 5 / D 7 / C 9.5 / B 12 / A 15 / S 17.5, ExpectedRunXP 출발 4000(프로젝트 설정, 실측 후 조정 — 이 값 하나로 모든 등급 곡선이 같이 움직임).
- 은퇴 포인트의 `floor(레벨/10)` 항은 그대로 둔다 — 높은 등급일수록 오래 키워야 크게 남는 구조.

### 7.2 능력치 (웹 → 원정 해석) [제안]
| 능력치 | 원정 효과 | 상한 |
|---|---|---|
| HP | 최대 체력 | — |
| ATK | 모든 피해의 기준. 피해 = `ATK × 배율 × 100/(100+DEF)` × (0.9~1.1) | — |
| DEF | 받는 피해 감소, 같은 공식 | — |
| SPD | 기본 공격 속도 배율 = `1 + SPD/100` | — |
| CRIT | 치명타 확률(%), 피해 ×1.6 | 75% |
| DODGE | 대시 쿨타임 감소 `DODGE × 1%`(최대 50%) + 피해 무효 확률 `DODGE × 0.2%`(최대 10%) | — |
| SPECIAL | 자동 기술 쿨타임 감소 `SPECIAL × 0.5%`(최대 40%) | — |
- 최종 능력치 계산 순서는 웹과 동일: 레벨 → 재능(배수, 고정) → 훈련(고정) → 장비(고정) → 가문 강화(배수) → 반올림·상한.

### 7.3 재능 [확정: 웹 15종 출발]
- 웹 TALENTS 15종(광전사~불멸의 전설, 희귀도 가중치 포함)을 그대로 이식하고, EA까지 약 20종으로 확장 [제안].
- 추가 5종은 액션용 효과(예: "대시 후 1초간 공격 속도 +30%", "처치 시 낮은 확률로 회복") [제안] — GAS GE/태그로 구현.
- **용병 성격 재능 [확정 방향 2026-11-12 / 제안 목록]**: 재능 일부가 원정 경로를 바꾼다 — 같은 던전이라도 용병마다 다른 판. EA 4~5종, 위 20종과 별도로 추가(총 약 25종) [제안].
  - 탐욕가: 황금 방 가중치 ×2, 탐욕의 냄새 +10% 빠르게 오름
  - 정찰병: 포털 너머 방의 난이도·보상 배율이 보임
  - 겁쟁이: 구역마다 한 번, 구역 중간에도 탈출 문 등장
  - 사냥꾼: 정예 방 가중치 ×2
  - 순례자: 휴식터 가중치 ×2

### 7.4 장비 [확정 + 제안]
- 슬롯 3개: 무기 / 방어구 / 장신구 [확정].
- **무기 = 기본 공격 방식을 정함** [확정]. EA 공격 방식 4종:

| 방식 | 동작 | 특징 |
|---|---|---|
| 단검 (기본, 길드 지급) | 근접 빠른 찌르기 | 약함, 소실 안 됨 |
| 검 | 전방 부채꼴 휘두르기 | 근접·높은 피해 |
| 활 | 단일 투사체 | 긴 사거리 |
| 지팡이 | 대상 위치 범위 폭발 | 느림·광역 |
- 공격 모션은 방식당 1개 [확정].
- 아이템 수 약 30종 [제안]: 무기 3방식 × 4티어 = 12, 방어구 8, 장신구 10. 웹 아이템 12종을 출발점으로 변형.
- 아이템 등급(희귀도) 5단계 [제안]: 일반/고급/희귀/영웅/전설. EA는 **고정 수치**(랜덤 옵션 없음).
- **아이템 요구 등급 [확정]**: 티어별로 장착 가능한 최소 용병 등급이 있다 — 1티어 F / 2티어 D / 3티어 B / 4티어 A. 요구 등급 미달 용병은 장착 불가(창고·장비 화면에서 회색 + "요구 등급 B" 표시).
  - 이유: 무료 F 용병 + 좋은 장비가 구입한 상위 등급을 이기면 "더 좋은 용병을 산다"는 핵심 재미가 무너짐. 창고에 쌓인 좋은 장비가 상위 등급 계약의 동기가 됨.
  - 기본 단검은 요구 등급 없음.
- **드롭 티어 확률 [확정 방향 / 제안 수치]**: 단계 깊이와 용병 등급에 따라 높은 티어 확률 증가. 출발 표(1/2/3/4티어 %): F·E 용병 1단계 80/20/0/0 → 3단계 50/40/10/0, D·C 용병 1단계 50/40/10/0 → 3단계 20/45/30/5, B 이상 1단계 20/40/30/10 → 3단계 5/25/45/25. 보스는 한 단계 위 표 사용. 요구 등급을 넘는 티어도 드롭됨(창고 보관 → 다음 용병용).
- DataTable 아이템 행에 `RequiredGrade` 필드 추가.
- **M7-3 구현 [확정 2026-11-18]**: 드롭 확률은 DT_Grades의 DropZone1/2/3/DropBoss 열(T1~T4 %). 2구역은 1·3구역 중간값, 보스는 3구역보다 한 단계 위: F·E 80/20/0/0 · 65/30/5/0 · 50/40/10/0 · 35/45/18/2, D·C 50/40/10/0 · 35/43/20/2 · 20/45/30/5 · 10/40/38/12, B·A·S 20/40/30/10 · 12/33/37/18 · 5/25/45/25 · 2/18/45/35. 상자 단계 = 엘리트 현재 구역 / 황금 고블린 한 단계 위 / 보스 처치 보스 단계 1개(즉시 지급). 아이템은 주울 때 추첨. 미확보 아이템은 탐욕에 티어×50골드로 반영. EA 출발 아이템 14종 = 웹 12종(무기는 모두 검 방식) + T1 활·지팡이.
- **용병 주무기 [확정 2026-11-18]**: 계약 후보마다 주무기 방식(검/활/지팡이)이 무작위로 정해지고 후보 정보에 표시된다. 맨손이면 주무기 방식으로 공격(단검은 데이터 없을 때의 대비용). 장착 무기가 주무기와 같은 방식이면 기본 공격 피해 +15%(설정값), 다른 방식도 장착 가능. 주무기는 유산으로 상속되지 않는다(M9에서 재검토).

- **M8-2 구현 [확정 2026-11-20]**: 창고 화면 = 장착 슬롯 3개 + 보관함(무기/방어구/장신구 3칸, 칸별 스크롤) + 오른쪽 정보 패널(같은 슬롯 장착품과 능력치 비교, 주무기 일치 표시, 장착 불가 이유). 카드 배경 = 티어 색(회/초/파/보). 장착·해제 즉시, 아이템 판매는 확인 창. 창고가 가득 차면 해제 불가(자동 판매 방지). 상점 = 창고 화면의 [보관함 | 상점] 전환: 1·2티어(설정 ShopMaxTier) 중 서로 다른 4개(ShopOfferCount) 진열, 원정 종료·새 저장 시 갱신, 구매한 진열은 빠짐, 가격 = 아이템 Price, 구매는 확인 창, **창고가 가득 차면 구매 거부**. 진열 교체(리롤)·명성 연동 티어는 M9.
- **이름 [확정 2026-11-24]**: 메뉴·화면 이름은 **보급소**, 안의 탭은 [보관함 | 상점]. 화면 문구의 "창고"는 "보관함"으로 통일(코드 이름 Stash는 유지).
- **상점 등급 [확정 2026-11-25, M9-2b]**: 골드로 올림(설정 ShopUpgradeCosts: 5,000G / 15,000G, 최고 3등급, 금액은 M9 밸런스에서 재조정). 등급 N = N~N+1티어 진열. 2등급부터 4칸 중 1칸은 항상 1티어(전사 후 F 용병용). 올리면 진열을 바로 새로 뽑음. 위의 ShopMaxTier 설정과 "명성 연동 티어" 계획을 대체. 보관함 목록은 슬롯별 2열.

### 8.5 명예의 전당 [확정: 웹 계승]
- 기록: 이름, 등급, 최종 레벨, 재능, 탈출 수, 보스 처치 수, 최고 도달 단계, 벌어온 골드, 떠난 방식(은퇴/판매/전사), 날짜.

### 8.5.1 길드 의뢰 [확정 방향 2026-11-12 / 제안 세부, M8]
- 출정 전 의뢰판에서 의뢰 3개 중 1개 선택(안 골라도 됨). 원정 종료마다 갱신.
- 조건 예 [제안]: 황금 방 2개 클리어 / 3구역 정예 방 클리어 / 피해 0으로 방 1개 / 냄새 3단계 이상으로 탈출 / 상점에서 골드 안 쓰고 2구역 탈출 / 보스 처치.
- 보상: 골드 + 용병 경험치(드물게 가문 포인트). **탈출 성공 시에만** 지급. EA 약 10종.
- **M8-3b 구현 [확정 2026-11-23]**: DT_Requests(이름 · 종류 · 목표 · 보상 골드/경험치/가문 포인트 · 가중치). 종류 7개 = 구역 도달 / 적 처치 / 정예 처치 / 보스 처치 / 황금 방(고블린 처치) / 정예 방(정예 전멸로 완료) / 탐욕 단계(탈출 시점). 출정 버튼 → 출정 확인 창이 곧 의뢰판(의뢰 3개 + "의뢰 없이 출정" + 취소). 진열 3개는 가중치로 서로 다르게, 원정 종료·새 저장·빈 목록일 때 갱신. 보상에 가문 강화 보너스 미적용. 결과 화면에 "의뢰 완료 / 실패(진행도)". "피해 없는 방"·"상점 지출 없음" 의뢰와 원정 중 진행도 HUD는 M9.
- 의도: 경로 선택에 이유를 주고, 길드 층과 원정 층을 잇는다.

### 8.6 경제 페이싱 목표 [제안 — 수치는 회색 박스에서 맞춤]
- 첫 플레이: F 용병으로 1~2단계 탈출 3~4회 → 첫 D 계약 가능.
- 첫 은퇴(명성 5, D 해금)까지 약 30~45분.
- 첫 S 해금까지 약 10~15시간(EA 콘텐츠 분량 기준).
- 원정 골드는 웹처럼 **용병 등급 보정**을 곱해 상위 등급 계약가를 따라가게 한다.

### 8.7 칭호 [확정 2026-11-24, M9-2]
- **길드 누적 기록**(계정 전체: 처치, 엘리트 처치, 보스 처치, 탈출, 용병 전사, 원정 골드)으로 해금. 해금 상태는 저장하지 않고 기록으로 매번 계산. 처치·엘리트 처치는 사망해도 누적, 탈출·원정 골드(가문 보너스 적용 후)는 탈출 시만, 전사는 용병 사망 시.
- **용병마다 1개 장착**(길드 → 용병 화면 [칭호 변경], 원정 중 변경 불가). 용병이 떠나도 해금은 유지.
- **칭호 창**: [획득 N | 미획득 N] 탭. 획득 = "칭호 없음" + 해금 칭호(누르면 즉시 장착, 장착 중 강조, 창 유지). 미획득 = 이름·보너스 + 진행도(누를 수 없음).
- **보너스**: 스탯은 가문 다음 단계(재능과 같은 비율 + 고정값), 탈출 골드·경험치 %는 가문 보너스에 더함.
- **표시**: 원정 중 영웅 머리 위(HP 바 위)에 등급 색(일반 흰 / 희귀 파랑 / 영웅 보라 / 전설 금), 결과 화면에 "새 칭호" 줄.
- **EA 14종 (DT_Titles)**: 사냥꾼·학살자·전장의 재앙(처치 1천/5천/2만, 공격 +2/+3/+5%) / 생환자·노련한 생환자·불굴(탈출 5/20/50, 최대 HP +3/+5/+8%) / 보스 사냥꾼·용사·전설(보스 1/5/15, 치명 +1/+2/+3) / 정예 사냥꾼·정예 학살자(엘리트 50/200, 속도 +3/+5) / 황금손·대상인(원정 골드 5천/2.5만, 탈출 골드 +5/+10%) / 피로 쓴 역사(용병 전사 10, 경험치 +10%).
- M9-2 이전 저장은 명예의 전당·현재 용병 기록으로 탈출·보스·골드·전사를 한 번 이어받음(처치는 0부터).

## 11. 기술 구조 (A+B 결합) [확정 방향 + 제안 세부]
```
길드 층 (순수 C++)
  UGameInstanceSubsystem "길드 서브시스템"
   - 저장 데이터 보유(골드, 명성, 가문 포인트·강화, 유산 재능, 창고, 현재 용병, 계약 후보, 명예의 전당, 원정 중 플래그)
   - 계약 후보 생성, 계약·은퇴·판매, 훈련, 상점, 저장/로드(USaveGame)
  USTRUCT 용병 데이터 + 능력치 계산 함수(웹 computeStats 순서)
        │ 원정 시작: 최종 능력치를 한 번, 한 방향으로 전달
        ▼
원정 층
  플레이어 캐릭터 + ASC + AttributeSet
   (HP, MaxHP, ATK, DEF, AttackSpeed, Crit, DodgeNegate, DashCDR, SkillCDR, PickupRadius, XPGain)
   - 대시 = GameplayAbility (무적 = 태그)
   - 자동 기술 = C++ UObject(`UMLAutoSkill`) + 타이머, 수치는 기술 BP 기본값(레벨별 배열), 쿨타임 = 기본 × (1 − SkillCooldownReduction 속성)
   - 패시브·재능 효과·버프 = GameplayEffect (SetByCaller)
   - 적 → 플레이어 피해 = 피해 GE + SetByCaller, DEF 공식은 AttributeSet에서 처리
  기본 공격 = 장착 무기 행을 읽는 컴포넌트(타이머 구동)
  원정 GameMode: 구역·방 흐름(방 목표 → 포털 3개 / 구역 끝 탈출 문), 방 종류 적용, 탐욕의 냄새, 보스, 결과 집계
        │ 탈출 시: 결과(골드, 아이템, 용병 경험치)를 한 번에 길드 층에 반영
        ▼
적 무리 (순수 C++)
  월드 서브시스템 하나가 풀링된 가벼운 Pawn을 일괄 이동(CharacterMovement 없음) — 틱은 이 서브시스템 하나만
  HP·상태이상(둔화·화상)은 서브시스템이 관리, 플레이어 → 적 피해는 C++ 피해 함수 하나
  투사체·경험치 보석도 풀링
```
